# CODSOFT Java Programming Virtual Internship

This repository contains the projects completed during the **CodSoft Java Programming Virtual Internship**. The projects demonstrate core Java programming concepts including Object-Oriented Programming (OOP), file handling, user input validation, loops, conditional statements, and data management.

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* File Handling
* Exception Handling
* Collections Framework
* Console-Based User Interface

---

## Task 1: Number Game

### Description

A console-based number guessing game where the system generates a random number and the user attempts to guess it.

### Features

* Generates a random number between 1 and 100
* Accepts user guesses
* Provides feedback if the guess is too high or too low
* Limits the number of attempts
* Supports multiple rounds
* Displays the user's score based on performance

---

## Task 2: Student Grade Calculator

### Description

A Java application that calculates a student's total marks, average percentage, and grade based on marks entered for multiple subjects.

### Features

* Input marks for each subject
* Calculate total marks
* Calculate average percentage
* Assign grades based on percentage
* Display complete result summary

---

## Task 3: ATM Interface

### Description

A console-based ATM simulation that allows users to perform basic banking operations.

### Features

* Withdraw money
* Deposit money
* Check account balance
* Input validation for transactions
* Bank account integration
* User-friendly menu-driven interface

### Classes Used

* ATM
* BankAccount
* Main

---

## Task 4: Currency Converter

### Description

A Java application that converts an amount from one currency to another using predefined exchange rates.

### Features

* Select base currency
* Select target currency
* Enter amount for conversion
* Convert amount using exchange rates
* Display converted amount

---

## Task 5: Student Management System

### Description

A student management application used to store and manage student records.

### Features

* Add student records
* Remove student records
* Search for students
* Display all students
* Edit existing student information
* Store student data in a file
* Input validation for student details

### Classes Used

* Student
* StudentManagementSystem
* Main
